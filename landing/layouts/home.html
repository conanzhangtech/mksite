Project mksite · a Hugo theme · MIT licence

Write Markdown files. Get a website.

mksite is a free theme for Hugo. It turns a folder of text files into a portfolio, a product page or a documentation site. Research papers open in a reader on the page, and your résumé prints to PDF.

What it will not do

It has no editor. You write the files in any text editor and Hugo builds the site.

It is not a page builder. The layouts are fixed. You choose a palette, a footer and the order of the menu, and you cannot drag things around.

It needs Hugo 0.146 or newer, because the templates use the layout folders Hugo introduced in that version.

I have tried the PDF reader in Chrome only. Firefox and Safari should work, but I have not checked.

Start in five minutes

  1. Make a site with hugo new site my-site.
  2. Clone the theme into themes/mksite and copy exampleSite/hugo.toml over yours.
  3. Run hugo server, open the address it prints, and replace the sample text with your own.
